## v0.1.0 — first tagged release

First tagged snapshot of Blukios Marketplace, taken from a CI-gated,
production-deployed `main`.

### Platform

- Multi-vendor marketplace for gadgets and electronics, Indonesian market.
- Two apps from one frontend codebase: buyer (`blukios.store`) and seller +
  admin (`seller.blukios.store`), with one-time-token cross-domain SSO.
- Laravel 12 API, Vue 3 SPA, FastAPI chat assistant (Ollama + RAG), FastAPI
  recommendation service (content-based + collaborative SVD), Laravel Reverb
  real-time chat.

### Highlights

- Server-authoritative checkout: buyer/store/shipping/voucher all re-validated
  server-side.
- Escrow payments via Midtrans; seller funds held until order completion;
  webhook-replay-safe ledger.
- Variant-aware pricing and stock with MySQL↔MongoDB compensation.
- `Money` fixed-point value object introduced (B3.1); pilot on
  `transaction_details.subtotal`.

### Infrastructure

- Jenkins pipeline: per-service change detection, lint/static/test/audit for the
  API and the two Python services and the frontend, a gitleaks secret scan, and
  an in-place production deploy with SHA verification and a health check.
- Prometheus + Grafana monitoring, k6 load scenarios.

### Known limitations

- Money calculation migration (B3.2) not done — tax, voucher and admin fee are
  not yet on the `Money` primitive; see `api-blue/docs/money-contract.md` §6.
- End-to-end Midtrans Snap payment flow not yet verified in an automated test.
- `products.price` is not integer-constrained yet.
- `docker-compose.yml` is a development configuration and must be hardened for
  any deployment (see `SECURITY.md`).
- The gitleaks stage is non-blocking and does not yet exclude `vendor/`.

### Housekeeping

- Repository documentation added (`README`, `CONTRIBUTING`, `SECURITY`,
  `CHANGELOG`, GitHub templates, root `.env.example`).
- 21 merged branches cleared; `feat/hp-layout-restructure` archived as tag
  `archive/hp-layout-restructure`.
